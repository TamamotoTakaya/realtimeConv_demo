# リアルタイム音声対話の試作アプリ

ブラウザでAIキャラクターと会話するアプリです。プロフィールや知識データを編集し、同じ質問への返答がどう変わるかを試せます。

以下はWindows向けの手順です。コマンドは、VS Codeの上部メニューから **「ターミナル」→「新しいターミナル」** を開き、画面下の入力欄に貼り付けて実行してください。

## 1. 必要なものを確認する

- **VS Codeなどのエディタ**：設定やコードを編集します。VS Code以外のテキストエディタが既にインストールされているなら、インストール不要です。[VS Codeのダウンロード](https://code.visualstudio.com/)
- **Node.jsとnpm**：アプリの起動と、必要なライブラリの導入に使います。バージョンはv24.13.0を推奨します。[Node.jsのダウンロード](https://nodejs.org/en/download/)
- **Git**：GitHubからアプリのファイルを取得します。[Gitのダウンロード](https://git-scm.com/downloads)
- **Chromeなどのブラウザ**、**インターネット接続**、**音声を聞ける環境**。声で話す場合はマイクも使います。
- **OpenAI APIキー**：研究用プロジェクトでRealtime APIを使えるキーが必要です。入手方法が分からない場合は担当者に確認してください。

Node.js・npm・Gitが入っているかは、ターミナルで以下を**1行ずつ**実行して確認できます。

```powershell
node --version
npm.cmd --version
git --version
```

それぞれバージョン番号が出れば、インストール済みです。「認識されません」などと表示されたものだけインストールしてください。Node.jsを新しく入れる場合は、公式ページの **LTS（長期サポート版）** を選びます。npmは通常、Node.jsと一緒に入ります。インストール後はVS Codeを開き直して、もう一度確認してください。

詳細は下記からご確認ください。
[各ツールのインストール方法](How_to_install_tools.md)

## 2. GitHubからクローンする

VS Codeの **「ファイル」→「フォルダーを開く」** で、アプリを置きたい場所を開きます。そこで新しいターミナルを開いて、以下を実行します。1行目のURLは、案内されたリポジトリのURLに置き換えてください。

```powershell
git clone https://github.com/OWNER/REPOSITORY.git voice-agent-workshop
```

非公開リポジトリの場合は、招待を承認し、アクセス権のあるGitHubアカウントで認証してください。

クローンが終わったら、VS Codeで作成された `voice-agent-workshop` フォルダを開き直します。

## 3. APIキーを配置する

`voice-agent-workshop` の直下、**`voice-agent` フォルダの外側**に、`openai-api-key.txt` を作ります。中身はAPIキーだけを1行で記入します。

| `voice-agent-workshop` の直下にあるもの | 用途 |
|---|---|
| `voice-agent/` | アプリ本体。`package.json` や `vite.config.js` があります |
| `character-profile.txt` | キャラクターの基本プロフィール |
| `knowledge.json` | 会話中に検索する知識データ |
| `openai-api-key.txt` | 各自が作成するAPIキーのファイル |

**APIキーのファイルはGitHubにアップロードしないでください。** Windowsでファイルを作るときは、拡張子が二重になって `openai-api-key.txt.txt` にならないよう注意してください。

## 4. アプリを起動する

`voice-agent-workshop` を開いたVS Codeで、新しいターミナルを開き、以下を順に実行します。

```powershell
cd voice-agent
npm.cmd ci
npm.cmd run dev
```

`npm.cmd ci` は、アプリに必要なライブラリをまとめて入れるコマンドです。終わってから次の行を実行してください。macOSの場合は `npm.cmd` を `npm` に読み替えます。

ターミナルに `Local:` とURLが表示されたら、そのURLをブラウザで開きます。**アプリを使っている間はターミナルを開いたまま**にしてください。ターミナルでの `Ctrl+C` はサーバーの停止に使います。URLは右クリックでコピーするか、ブラウザに手入力してください。

画面の **「接続」** を押し、マイクの許可が求められたら許可します。会話モードでは「自己紹介して」などと話しかけてください。試聴用に設定されている場合は、接続時にテスト音声が流れます。使い終わったら **「切断」** を押します。

## 5. 知識データを編集して試す

1. キャラクターの名前や話し方を変えたい場合は `character-profile.txt` を編集します。
2. 会話中に参照する知識を変えたい場合は `knowledge.json` を編集します。`keywords` は検索の手がかり、`text` は回答の材料です。まずは既存の項目の `text` を1か所変えてみてください。
3. 保存したら、ブラウザで **「切断」→「接続」** と操作し、同じ質問をして返答を比べます。

サーバー側の処理を編集する場合は `voice-agent/vite.config.js`、ブラウザの画面やエージェントの動作を編集する場合は `voice-agent/src/main.ts` を開きます。

## 次回起動するとき

VS Codeで `voice-agent-workshop` を開き、新しいターミナルで次を実行します。

```powershell
cd voice-agent
npm.cmd run dev
```

## うまくいかないとき

| 症状 | 確認すること |
|---|---|
| `npm.cmd` が認識されない | Node.jsを入れた後、VS Codeを開き直したか |
| `package.json` が見つからない | ターミナルで `cd voice-agent` を実行したか |
| ブラウザでページが開かない | サーバーが動いているか。`Local:` に表示されたURLを開いているか |
| APIキーファイルが見つからない | `voice-agent` の外側に置いたか。ファイル名と拡張子が合っているか |
| 接続したが音声が聞こえない | ブラウザのマイク許可、PCの音量、イヤホンなどの出力先を確認 |

エラーを担当者に伝えるときは、**どの手順で止まったかと、エラー文**を共有してください。APIキーは含めないでください。
